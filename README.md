# Mi primer respositorio 

En este mini proyecto he aprendia los siguienres comandos :

- `git clone `
- `git log` con los modificadores --oneline y --all
- `git checkout`
- `git diff` --staged
- `git add `
- `git commit` -m "mensaje"
- `git remote` incluyendo `get-url `y `set-url`
- `git merge` para arreglar una cosita
- `git push`

## mas cosas de markdown
Podemos formatear codigo unsado triple comillas ``` + el nombre del lenguaje

```java
public class Hellomarkdown {
    public static void main(String[] args) {
        System.out.println("Hello , markdown");
    }
}
```
